Assist Satellit im Browser flashen

Diese Seite flasht die zuletzt kompilierte Firmware direkt über ESP Web Tools (Web Serial) — ohne esphome run im Terminal. Funktioniert in Chrome oder Edge (Web Serial wird von Safari/Firefox nicht unterstützt).

Voraussetzung: einmal esphome compile assist-satellit.yaml im Terminal laufen lassen. Diese Seite lädt danach die dabei erzeugte firmware.factory.bin aus .esphome/build/ — bei jeder neuen Kompilierung reicht ein Neuladen der Seite.

Seite lokal servieren (Web Serial braucht einen sicheren Kontext):

cd "$(git rev-parse --show-toplevel)"
python3 -m http.server 8000

Dann im Browser öffnen: http://localhost:8000/web-flash/

Dein Browser unterstützt Web Serial nicht. Bitte Chrome oder Edge verwenden. Web Serial ist hier nicht erlaubt — Seite über http://localhost öffnen, nicht als file://.

Ablauf: Gerät per USB anschließen → Button klicken → seriellen Port aus der Browser-Auswahl wählen → flashen. Für spätere Updates ist OTA weiterhin der schnellere Weg: 

esphome run assist-satellit.yaml --device assist-satellit.local
Nur eine lokale Komfort-Seite fürs Erstflashen per USB, kein Ersatz für den ESPHome-Workflow. Details siehe CLAUDE.md / README.md.
