Lumi im Browser installieren

Home-Assistant-Voice-Satellit-Firmware für das Waveshare ESP32-S3-Touch-AMOLED-1.75 — Quelltext auf github.com/mohoel/home-assistant-voice-lumi. Läuft über ESP Web Tools (Web Serial) in Chrome oder Edge am Desktop — ohne Installation, ohne Terminal.

Voraussetzungen
Chrome oder Edge (Desktop) USB-C-Kabel mit Datenleitung Waveshare-Board per USB
Dein Browser unterstützt Web Serial nicht. Bitte Chrome oder Edge am Desktop verwenden. Web Serial ist auf dieser Seite nicht erlaubt. Diese Seite muss über https:// aufgerufen werden (nicht als heruntergeladene Datei).
So läuft das Flashen ab
  1. Board per USB anschließen.
  2. Oben auf „Gerät verbinden & flashen" klicken.
  3. Im Auswahldialog des Browsers den seriellen Port des Boards wählen.
  4. Meldet sich kein Port: Board in den Download-Modus bringen — BOOT gedrückt halten, kurz RESET drücken, dann BOOT loslassen — und den Dialog erneut öffnen.
  5. Flashvorgang abwarten (ein bis zwei Minuten). Nicht abstecken.
  6. Direkt danach öffnet sich automatisch das Fenster zur WLAN-Auswahl — ohne weiteren Klick.
  7. Ausnahme: Lief auf dem Board schon exakt dieselbe Firmware-Version (z. B. ein zweiter Testlauf), erkennt ESP Web Tools das, flasht gar nicht neu und zeigt direkt „Change Wi-Fi" statt der Auswahl — derselbe Dialog, nur ein Klick mehr und mit anderer Beschriftung.
Wichtig, bevor du klickst

Diese Firmware bringt dein WLAN nicht mit — in eine öffentlich gehostete Datei kann es schließlich nicht hinein. Du trägst es direkt nach dem Flashen im Browser ein; wie das abläuft, steht unten unter „Nach dem Flashen". Danach ist das Gerät fertig eingerichtet, Updates kommen später über Home Assistant.

Nach dem Flashen

Direkt nach dem Flashen fragt ESP Web Tools über dieselbe USB-Verbindung nach deinem WLAN (Improv Wi-Fi) — SSID und Passwort einfach im Dialog eintragen, kein Hotspot, kein Gerätewechsel nötig. Das Gerät verbindet sich direkt und meldet sich per mDNS im Netz.

Überspringst du diesen Schritt oder schließt die Seite vorher, findet das Gerät beim nächsten Start — mit Absicht — kein WLAN, denn diese Firmware kennt deines nicht. Es öffnet dann ersatzweise einen eigenen Hotspot, ungefähr Lumi Fallback Hotspot, mit einer Konfigurationsseite dahinter (Captive Portal):

  1. Am Handy oder Laptop mit diesem Hotspot verbinden.
  2. Öffnet sich keine Konfigurationsseite von selbst, im Browser http://192.168.4.1 aufrufen.
  3. Dort das eigene WLAN samt Passwort eintragen und speichern.
  4. Das Gerät verbindet sich damit und meldet sich per mDNS im Netz.

In Home Assistant taucht es danach unter Einstellungen → Geräte & Dienste als ESPHome-Gerät auf. Beim Hinzufügen fragt Home Assistant nach einem Verschlüsselungsschlüssel — das ist ein fest hinterlegter, nicht geheimer Platzhalter: 

Bw1nT2P6zfBP++xn1gTvfloJweHwPrXXRj0I01RdKZk=

Dieser Schlüssel steht offen im Quelltext (secrets.public.yaml) und schützt nichts — er ist nur nötig, damit Home Assistant sich überhaupt verbindet. Alles Weitere läuft danach über Home Assistant: Einstellungen sind ganz normale Entities, und neue Firmware-Versionen erscheinen unter Einstellungen → Geräte → Updates mit einem „Installieren“-Knopf — diese Seite braucht es dafür nicht mehr.

Diese Seite ist Teil von home-assistant-voice-lumi und wird bei jedem Firmware-Release (Git-Tag) automatisch neu gebaut (.github/workflows/release.yml). Quelltext und die volle Funktionsbeschreibung stehen im Haupt-README.
