Lumi im Browser installieren

Home-Assistant-Voice-Satellit-Firmware für das Waveshare ESP32-S3-Touch-AMOLED-1.75 — Quelltext auf github.com/mohoel/home-assistant-voice-lumi.

Diese Seite flasht die zuletzt veröffentlichte Firmware direkt über ESP Web Tools (Web Serial) — ohne Installation, ohne Terminal, ohne ESPHome auf dem eigenen Rechner. Funktioniert in Chrome oder Edge am Desktop (Web Serial fehlt in Safari und Firefox, auf dem Handy gibt es keinen USB-Seriell-Zugriff).

Wichtig, bevor du klickst: Diese Firmware ist ein anonymer Standard-Build ohne dein WLAN und ohne deinen persönlichen Zugangsschlüssel — beides kann in eine öffentlich gehostete Datei schließlich nicht hinein. Was das bedeutet, steht unten unter Nach dem Flashen. Für den dauerhaften Betrieb ist ein zweiter, lokaler Build mit eigenen Zugangsdaten sinnvoll (Anleitung im Haupt-README) — diese Seite ist der schnelle Weg, das Gerät überhaupt erst einmal zum Laufen zu bringen.

Voraussetzungen

  • Chrome oder Edge am Laptop/Desktop
  • USB-C-Kabel mit Datenleitung (nicht jedes Ladekabel überträgt Daten)
  • das Waveshare-Board, per USB an diesen Rechner angeschlossen

Flashen

  1. Board per USB anschließen.
  2. Unten auf „Gerät verbinden & flashen" klicken.
  3. Im Auswahldialog des Browsers den seriellen Port des Boards wählen.
  4. Meldet sich kein Port: Board in den Download-Modus bringen — BOOT gedrückt halten, kurz RESET drücken, dann BOOT loslassen — und den Dialog erneut öffnen.
  5. Flashvorgang abwarten (ein bis zwei Minuten). Nicht abstecken.
Dein Browser unterstützt Web Serial nicht. Bitte Chrome oder Edge am Desktop verwenden. Web Serial ist auf dieser Seite nicht erlaubt. Diese Seite muss über https:// aufgerufen werden (nicht als heruntergeladene Datei).

Nach dem Flashen

Das Gerät startet neu und findet — mit Absicht — kein WLAN, denn diese Firmware kennt deines nicht. Es öffnet stattdessen einen eigenen Hotspot, ungefähr Assist Satellit Fallback Hotspot, mit einer Konfigurationsseite dahinter (Captive Portal).

  1. Am Handy oder Laptop mit diesem Hotspot verbinden.
  2. Öffnet sich keine Konfigurationsseite von selbst, im Browser http://192.168.4.1 aufrufen.
  3. Dort das eigene WLAN samt Passwort eintragen und speichern.
  4. Das Gerät verbindet sich damit und meldet sich per mDNS im Netz.

In Home Assistant taucht es danach unter Einstellungen → Geräte & Dienste als ESPHome-Gerät auf. Beim Hinzufügen fragt Home Assistant nach einem Verschlüsselungsschlüssel — für diesen anonymen Build ist das ein fest hinterlegter, nicht geheimer Platzhalter: 

Bw1nT2P6zfBP++xn1gTvfloJweHwPrXXRj0I01RdKZk=
Dieser Schlüssel steht offen im Quelltext (secrets.public.yaml) und schützt nichts — er ist nur nötig, damit Home Assistant sich überhaupt verbindet. Für einen Schlüssel, der wirklich nur dir gehört, einmal lokal neu flashen: esphome run assist-satellit.yaml --device assist-satellit.local mit einem eigenen secrets.yaml (Anleitung im Haupt-README). Updates danach laufen normal per OTA, ganz ohne diese Seite.
